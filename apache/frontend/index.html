SEGURIDAD Y CALIDAD EN EL DESARROLLO

Una tienda para entender seguridad web de punta a punta.

La interfaz consume un backend Spring Boot protegido por JWT. Apache entrega el frontend por HTTPS y actúa como reverse proxy hacia la API.
